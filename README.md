# Veystrix Homebrew tap

Install [Veystrix](https://github.com/Veystrix/Veystrix-Engine), a local inference engine for Apple Silicon Macs:

```bash
brew install Veystrix/veystrix/veystrix
```

Update:

```bash
brew upgrade veystrix
```
